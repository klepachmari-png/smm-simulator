# МК SMM 1.0

Офіційний репозиторій лендінгу та п’ятиденного SMM-симулятора Марії Клепач.

## Структура

- `public/index.html` — основний лендінг.
- `public/simulator.html` — симулятор.
- `public/login.html` — вхід учасника через email і одноразовий код.
- `public/` — усі стилі, матеріали та файли для завантаження.
- `supabase/schema.sql` — таблиця прогресу та правила доступу.
- `netlify.toml` — публікація з GitHub через Netlify.

## Безпека даних

Кожен учасник бачить і змінює лише власний прогрес. Доступ визначається
авторизованим користувачем, а не браузером, Telegram-ніком чи параметром URL.
Публічний ключ Supabase може зберігатися у `public/config.js`; сервісний ключ у
репозиторій додавати заборонено.
