ГОТОВИЙ ПАКЕТ ДЛЯ NETLIFY

1. Розпакуй ZIP.
2. Відкрий https://app.netlify.com/drop
3. Перетягни папку netlify_simulator_ready у вікно Netlify.
4. Netlify дасть адресу виду https://....netlify.app
5. Перевір адресу https://....netlify.app/simulator
6. Саме її постав у кнопку «Почати симулятор» у SendPulse.

Логіка:
бот → email → 6-значний код → актуальний симулятор → хмарний прогрес.
